Exploratory Data Analysis (EDA)

Project Overview

This project performs Exploratory Data Analysis on the Iris Flower Dataset using Python.

Tools Used

- Python 3.12.8
- Pandas
- NumPy
- Matplotlib
- Seaborn

Tasks Performed

1. Dataset exploration
2. Data structure and data types
3. Statistical analysis
4. Missing value detection
5. Duplicate detection
6. Outlier detection
7. Trend and pattern identification
8. Data visualization

Graphs Created

- Histogram
- Scatter Plot

Conclusion

The Iris dataset was successfully analysed using Python. Statistical methods and visualizations helped identify patterns and understand the dataset.

Project Status: Completed.
